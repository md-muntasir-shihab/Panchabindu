## 1. Attack Surface & Entry Points

| Surface / Endpoint | Method | Auth / RBAC Gate | Primary Risks Evaluated |
| --- | --- | --- | --- |
| `GET /api/admin/workspace` | GET | `verifyAdminSessionToken` + `isFirstLoginGateCleared` (local offline preview bypass only when `NODE_ENV !== 'production' && NODE_ENV !== 'test'`) | Cross-origin data read, header leakage, vendor/role over-exposure |
| `POST /api/admin/workspace` (`order_grid_action`, `update_order_courier_meta`, `update_full_order`, `input_manual_mfs`, `review_manual_mfs`, `generate_print_slips`, `auto_sync_orders_geo`, `sync_courier_tracking`) | POST | Signed session + `verifyOriginAndCsrf` (enforced outside offline preview bypass) + `canExecuteWorkspaceAction` + `super_admin` gate for `update_full_order` | Stored XSS via tracking URLs, order state-machine skip, 2-step payment ledger bypass, silent price/status tampering, unsupported courier injection |
| `POST /api/print/:orderNo` | POST | Signed session + `verifyOriginAndCsrf` + 4KB body cap + Zod copy enum + vendor line scoping + reprint reason gate + `super_admin` gate on `finance` copy | Oversized payload DoS, unauthorized finance slip disclosure, unlogged reprints |
| Client CSV Exporters (`admin-erp-client.tsx` `handleExportOrders` & `bulk-csv-exporter.ts` `escapeCsvCell`) | Client Export | Admin UI | OWASP CSV / Formula Injection (`=`, `+`, `-`, `@`, `|`, leading whitespace/control chars), premature `URL.revokeObjectURL` |
| Print QR Renderer (`print-engine-panel.tsx` `<QRCodeSVG>`) | Client Render | Admin UI | Stored XSS URI (`javascript:` / `data:`) in QR code, uncaught `new URL()` crash DoS on malformed stored URLs |
