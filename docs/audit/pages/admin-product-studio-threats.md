# Product & Category Studio — Threat Model & Security Audit

> Page: **Product & Category Studio** (`/admin` → `Product Studio`: `All Products Catalog`, `Category Manager`, `Review Moderation`, `Product Linkage Review` + `CatalogImportPanel` CSV Import + 4 Modals: **Product Editor**, **Product Linkage Snapshot**, **Archive Confirmation**, **Create/Edit Category**)
> Role: **Super Admin** (catalog writes: `upsert_product`, `delete_product`, `upsert_category`, CSV import `/api/catalog/import`, media upload/approval `/api/media`) + **Super Admin / Marketing Manager** (`moderate_product_review` via `catalog:update`)
> Audit Date: **2026-11-21**
> Branch: **`audit/admin-product-studio-2026-11-21`**

## 1. Attack Surface & Entry Points

| Surface / Endpoint | Method | Auth / RBAC Gate | Primary Risks Evaluated |
| --- | --- | --- | --- |
| `POST /api/admin/workspace` (`upsert_product`) | POST | Signed session + `verifyOriginAndCsrf` + `super_admin` (`catalog:create`/`update`) | 3-tier Poisha pricing tampering (`salePricePoisha < supplierCostPoisha` or margin mismatch), direct `stockOnHand` bypass on existing variants, unsafe image URLs (`javascript:`, `data:`, credentialed URLs), unbounded strings/arrays (`variants`, `specs`), control-character injection |
| `POST /api/admin/workspace` (`delete_product`) | POST | Signed session + `verifyOriginAndCsrf` + `super_admin` (`catalog:delete`) | Destructive hard-delete breaking past order line references, SKUs, and stock audit trails despite logging `PRODUCT_ARCHIVED` |
| `POST /api/admin/workspace` (`upsert_category`) | POST | Signed session + `verifyOriginAndCsrf` + `super_admin` (`catalog:update`) | Duplicate category `slug` collision breaking storefront `/category/:slug` routing, unsafe `iconName` characters, unbounded `sortOrder` & strings, control-character injection |
| `POST /api/admin/workspace` (`moderate_product_review`) | POST | Signed session + `verifyOriginAndCsrf` + `catalog:update` (`super_admin`, `marketing_manager`) + `isFirstLoginGateCleared` | Service-level defense-in-depth missing explicit `hasModulePermission(ctx, 'catalog', 'update')` and first-login gate check, invalid moderation decision enum |
| `POST /api/catalog/import` | POST | Signed session + `verifyOriginAndCsrf` + `super_admin` + `previewHash` integrity check | Forged/mismatched `previewHash` on commit, N× disk read amplification (`readPhase4BStore` inside row loop up to 200×), partial mid-batch corruption on commit error, overlong/control-char CSV fields, unknown vendor/category/duplicate SKU injection |
| `POST/GET /api/media` & `/api/media/[assetId]` | GET/POST | Signed session + `verifyOriginAndCsrf` + `super_admin` + MIME/magic-byte check | Polyglot/SVG XSS file upload, stack trace leakage on invalid uploads or unconfigured storage |
| Admin UI (`ProductManagementStudioPanel` & `CatalogImportPanel`) | Client DOM | Admin UI (`isSuperAdmin` & `canModerateReviews` visibility gating) | `window.confirm`/`window.alert` broken in iframes, sticky preview banner clipping modal headers, fake default cotton spec silently added on edit, editable existing-variant stock causing guaranteed server rejections, WCAG 2.1 AA label/contrast/touch/mobile-zoom defects |

## 2. Threat Matrix & Citations (OWASP / CWE)

| ID | Threat Class | Reference | Finding Before Fix | Remediation & Proof | Status |
| --- | --- | --- | --- | --- | --- |
| **T-PS-01** | Destructive Hard-Delete Breaking Financial & Order History | Data Integrity / Audit Trail Preservation | `deleteAdminProduct` spliced products directly out of storage (`splice(idx, 1)`) even with active stock or past orders, while the audit log falsely recorded `PRODUCT_ARCHIVED`. | Converted `deleteAdminProduct` (API & frontend repository parity) to **always soft-archive** (`status = 'archived'`, `isFeatured = false`, returning `{ success: true, archived: true }`), preserving SKUs, stock, and order history. Replaced `window.confirm`/`window.alert` with an accessible inline Archive Confirmation dialog. Verified via `test:catalog:api` & `test:catalog:browser`. `[EXECUTED]` | **FIXED** |
| **T-PS-02** | Input Bounds, Slug Collision & Control-Char Hardening | OWASP API3:2023 / OWASP A03:2021 (Injection) / CWE-20 | `upsert_product` and `upsert_category` accepted arbitrarily large names/descriptions, unbounded `variants`/`specs` arrays, arbitrary `iconName` strings, out-of-range `sortOrder`, control characters, and duplicate category `slug` collisions. | Added linear `hasAsciiControlChars` checks, strict length/array caps in both Zod (`workspace/route.ts`) and repository (`repository.ts`), `iconName` allowlist `/^[A-Za-z0-9_-]+$/`, `sortOrder` `0..9999`, `weightGrams` `10..100000`, and unique `slug` collision check in `upsertAdminCategory`. Verified via `test:catalog:api` (7/7 PASS). `[EXECUTED]` | **FIXED** |
| **T-PS-03** | CSV Bulk Import Resource Amplification & Partial-Batch Corruption | OWASP API4:2023 (Unrestricted Resource Consumption) / Atomicity | `validateCatalogImport` re-read `readPhase4BStore()` on every row (up to 200 disk reads per request), lacked linear control-char & field-length bounds, and `commitCatalogImport` wrote products sequentially without rollback on mid-batch failure. | Hoisted active category & vendor lookups into `Set`s outside the row loop, added linear control-char & length caps on every imported column, and wrapped `commitCatalogImport` with a `structuredClone` pre-batch snapshot rollback on any mid-batch error. Verified via `test:catalog:api` & `audit:eslint:catalog`. `[EXECUTED]` | **FIXED** |
| **T-PS-04** | Service-Layer Authorization Parity on Review Moderation & Stock Integrity | OWASP A01:2021 (Broken Access Control) / CWE-863 | `moderateProductReview` only checked `role !== 'vendor'` instead of enforcing `hasModulePermission(ctx, 'catalog', 'update')` and `isFirstLoginGateCleared(ctx)`. In UI, non-`super_admin` staff saw catalog write buttons (`403`), and existing variant `stockOnHand` remained editable even though the server rejects direct stock edits. | Added `hasModulePermission(ctx, 'catalog', 'update')` & `isFirstLoginGateCleared(ctx)` inside `moderateProductReview`; gated catalog-write controls to `isSuperAdmin` and review buttons to `canModerateReviews`; locked existing variant `stockOnHand` input as `readOnly` with an audit hint directing operators to reason-logged Inventory Adjustment. Verified via `test:catalog:api` & `test:catalog:browser`. `[EXECUTED]` | **FIXED** |
| **T-PS-05** | Modal Clipping, Fake Spec Mutation, Accessibility & Localization Defects | WCAG 2.1 AA / Responsive Ergonomics | Sticky preview banner clipped modal tops; `handleEditProduct` silently injected `{ Material: '100% Pure Cotton' }`; 26 `jsx-a11y/label-has-associated-control` errors + 21 unused-var warnings; `<16px` mobile inputs; broken EN/BN labels (`"Revoke"`, `"Cancelled"`, `"1 variants"`, untranslated modal titles). | Measured sticky preview banner height (`bannerOffsetPx`) across all 4 modals (`dialogTop >= bannerBottom - 1`); removed fake cotton spec injection + added Spec Remove buttons; wired `useId()` `htmlFor`/`id` + `role="tablist"`/`"tab"`/`"tabpanel"`; enforced `text-base lg:text-xs` (`>=16px` mobile) & `44px` touch targets; fixed all EN/BN labels, pluralization, and high-contrast badges. Verified 0 ESLint issues and 0 Axe WCAG 2.1 AA violations across all 4 tabs, CSV import, and all 4 modals (`test:catalog:browser`). `[EXECUTED]` | **FIXED** |

## 3. External Security Research Applied (2026-11-21)

- OWASP Top 10:2025 / OWASP API Security Top 10:2023 (API3:2023 BOPLA, API4:2023 Unrestricted Resource Consumption) — drove pricing/stock write integrity, unique category slug checks, CSV import batch rollback & lookup hoisting, and strict payload bounds.
- OWASP File Upload & Media Security Cheat Sheet — verified `/api/media` SVG/MIME rejection without error/stack leakage and strict `https:` image URL validation.
