# Print Engine & Invoice Studio — Threat Model & Security Audit

> Page: **Print Engine & Invoice Studio** (`/admin` → Print & Invoice tab: `Print queue`, `Template settings`, `Print history`) + connected **Admin Orders Print Preview** drawer (`OrderPrintPreviewSheet`)
> Role: **Super Admin** (full access: Parts 1–3, Template Settings, Full Print History) + **Warehouse / Operations Staff** (`packaging_manager`, `order_moderator` via `print_engine:create` — Parts 1–2 & 4×6 Thermal only, Part 3 strictly redacted on server; `marketing_manager` & `vendor` denied `403`)
> Audit Date: **2026-11-21**
> Branch: **`audit/admin-print-engine-2026-11-21`**

## 1. Attack Surface & Entry Points

| Surface / Endpoint | Method | Auth / RBAC Gate | Primary Risks Evaluated |
| --- | --- | --- | --- |
| `POST /api/admin/workspace` (`generate_print_slips`) | POST | Signed session + `verifyOriginAndCsrf` + `canExecuteWorkspaceAction` (`print_engine:create`: `super_admin`, `packaging_manager`, `order_moderator`; `marketing_manager` & `vendor` denied `403`) | Excessive Data Exposure (Part 3 supplier costs, vendor payouts, margins, internal SKUs, staff notes leaked to staff), `sortBy: 'vendor'` side-channel oracle, unbounded batch size DoS, preview polluting `printCount` |
| `POST /api/admin/workspace` (`update_print_config`) | POST | Signed session + `verifyOriginAndCsrf` + `settings_control_center:update` (`super_admin` + `isFirstLoginGateCleared` only; all other roles `403`) | Privilege escalation (staff modifying invoice terms/titles), unbounded strings/checklist arrays, control-char injection, missing immutable audit trail |
| `POST /api/print/:orderNo` | POST | Signed session + `verifyOriginAndCsrf` + 4KB body cap (`413`) + `orderNo` length cap (`1..64`) + copy enum (`customer`, `packaging`, `finance`) + vendor line scoping + reprint reason gate (`422`) + `super_admin` gate on `finance` copy | Overlong `orderNo` parsing abuse, oversized body DoS, unauthorized `finance` copy access, unlogged reprints |
| Native Print Iframe Pipeline (`print-engine-panel.tsx` `executeNativeSlipPrint`) | Client DOM / Print | Admin UI | DOM/iframe injection via active element/attribute cloning (`<script>`, `<iframe>`, `on*` handlers, `javascript:`/`data:text/html` URLs), untrusted `baseURI`, iframe cleanup timer leak |
| Print Document Render (`PrintableSlipsDocument` & `OrderPrintPreviewSheet`) | Client Render | Admin UI | Unsafe product thumbnail `imageUrl` (`javascript:`/`data:`/credentialed URLs), `NaN`/`0` height scaling crash, Part 3 UI exposure to non-`super_admin` roles |

Conversely, `Template settings` UI rendered for non-`super_admin` staff even though `update_print_config` denied them. | Aligned `workspace-policy.ts` (`print_engine:create`) and `generateOrderPrintSlips` so authorized warehouse/ops staff generate Parts 1–2 & 4×6 Thermal slips while the server strictly strips `internalPart3: null`, disables `sortBy: 'vendor'` side-channel sorting, and filters `PRINT_FINANCE` audit events. `vendor` & `marketing_manager` remain denied (`403`). | **T-PE-02** | Print Iframe DOM Injection & Untrusted Media URLs | OWASP XSS Prevention / OWASP DOM-Based XSS / CWE-79 | `executeNativeSlipPrint` serialized `source.outerHTML` directly into an iframe document with unvalidated `document.baseURI`, and `PrintableSlipsDocument` rendered `item.imageUrl` directly into `<img src>`. | Added `sanitizePrintableClone` (clones DOM node, strips `script, iframe, object, embed, form, meta, base`, strips all `on*` inline handlers, neutralizes `javascript:`/`vbscript:`/`data:text/html` URLs), validated `document.baseURI` origin before `<base href>`, fixed `cleanupTimer` leak on `onafterprint`, and routed `item.imageUrl` through `safeStoreUrl`. | **T-PE-03** | Unbounded Batch & Template Configuration DoS / Injection | OWASP API4:2023 (Unrestricted Resource Consumption) / CWE-20 / CWE-770 | `generate_print_slips` accepted arbitrarily large `orderNos` arrays and arbitrary string lengths; `update_print_config` lacked max length/control-char bounds, checklist item count caps, `super_admin` service parity, and audit logging; `/api/print/:orderNo` lacked `orderNo` length cap. | Enforced `orderNos` deduplication + `1..100` batch cap + `1..64` char cap in Zod & service; enforced `super_admin && isFirstLoginGateCleared` + `2..100` title bounds (zero control chars via linear scan), `60..120` integer mm heights, `0..300` footer note, max `20` checklist items (`<= 160` chars each), plus immutable `PRINT_TEMPLATE_UPDATED` audit log; added `1..64` char `orderNo` validation on `/api/print/:orderNo`. ## 3. External Security Research Applied (2026-11-21)

- OWASP Top 10:2025 / API Security Top 10:2023 (API3:2023 Broken Object Property Level Authorization & API4:2023 Unrestricted Resource Consumption) — drove server-side stripping of `internalPart3` and batch/config bounds.
- OWASP XSS Prevention & HTML-to-Print/Iframe Hardening — drove DOM clone sanitization (`sanitizePrintableClone`), `<base>` origin validation, and `safeStoreUrl` image gating before native iframe print execution.
