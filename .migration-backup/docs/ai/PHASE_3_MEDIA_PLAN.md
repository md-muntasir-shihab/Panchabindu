2. Implement an authorized server-side intake with streaming/bounded body size and server-resolved vendor ID. Private staging only; randomized object keys, no client-selected tenant path, no arbitrary URL fetching. Inspect signatures and use a reviewed, supported image decoder to enforce dimensions/pixel limits, reject malformed images, re-encode and strip EXIF/GPS.
